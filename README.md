# Number Guessing Game

A simple command-line number guessing game built with Node.js.

The program randomly selects a number between 1 and 100, and the player must guess the correct number within a limited number of attempts.

## Features

- Random number between 1 and 100
- Three difficulty levels:
  - Easy: 10 chances
  - Medium: 5 chances
  - Hard: 3 chances
- Input validation
- Higher/lower hints after each guess
- Shows the number of attempts when the player wins

## Requirements

- Node.js

## How to Run

Open the terminal in the project directory and run:

```bash
node app.js
```

Then follow the instructions shown in the terminal.

## Example

```bash
Welcome to the Number Guessing Game!
I'm thinking of a number between 1 and 100.

Please select the difficulty level:
1. Easy (10 chances)
2. Medium (5 chances)
3. Hard (3 chances)

Enter your choice: 2
```
